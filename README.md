# Morrow Café — ₹150 OFF Campaign

A responsive campaign landing page for **Morrow Café, Sector 104, Noida**.

The experience is designed for visitors arriving from a QR code with very little context. It quickly explains the offer, collects the visitor's name and mobile number, generates a unique claim code through a backend API, and displays the code for use at the café.

## <a href="https://morrow-cafe-omega.vercel.app/"> Check Live  </a>

## Features

- Responsive ₹150 OFF campaign landing page
- Clear Morrow Café branding and offer presentation
- Name and mobile-number validation
- Backend API for secure claim processing
- Unique claim-code generation and dynamic display
- Copy-to-clipboard functionality


## Installation
1. Clone the Repository
   
   ```
   git clone https://github.com/Adityaawaik/morrow-cafe.git
   cd morrow-cafe
   ```

2. Install Frontend Dependencies
   
   ```
   cd morrow-cafe-frontend
   npm install
   ```
   Create a frontend .env file:
   VITE_API_URL=your backend url

   ```
   npm run dev
   ```
3. Install Backend Dependencies
   ```
   cd morrow-cafe-backend
   npm install
   ```
   Create a backend .env file:
   FRONTEND_URL=your frontend url
   ```
   npm start
   ```
